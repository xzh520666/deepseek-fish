# 成本控制（token 优化清单）

按重要性排序，全部已在默认配置里开启。

## 1. 让 DSH 知道真实上下文窗口（最关键）

`cordis.patch.yml` 里必须有：

```yaml
- id: llm-deepseek
  config:
    defaultContextWindow: 128000
```

**不配的后果**：插件默认认为窗口有 100 万 token → 自动压缩永不触发 → 会话一路涨到模型真实上限 → **API 返回 HTTP 400**，而且期间每次调用都在重发整段上下文。

## 2. 压缩与裁剪调紧

```yaml
compaction-basic:
  thresholdRatio: 0.5    # 到窗口 50% 就压缩（默认 80% 太晚）
  maxTokens: 2000        # 摘要长度
  retainRatio: 0.12      # 只保留 12% 原文
tool-result-pruner:
  thresholdChars: 20000  # 工具结果超 2 万字就裁剪
  headChars: 12000
  tailChars: 1000
```

## 3. 学习类任务降配 + 轮换（省得最多）

```json
"slang": {
  "learnerModel": "deepseek-v4-flash",   // 文本任务不需要视觉大模型
  "learnerEffort": "low",                // 推理从 max 降到 low
  "learnerRotateBytes": 81920,           // 学习会话超 80KB 就换新
  "learnerRotateTasks": 3                // 或跑满 3 个任务就换新
}
```

⚠️ **必须轮换**：学习会话会累积联网搜索结果，攒到几 MB 后每次任务都要把整段当"新输入"重发，一次能烧掉几十万 token（实测单次 ¥1+）。

## 4. 每轮固定注入瘦身

```json
"roleCard": { "fullEveryTurns": 8 },          // 完整人设卡每 8 轮注入一次
"crossChat": { "maxLines": 10 },              // 跨会话时间线 10 条
"longMemory": { "maxLines": 6 },              // 长期记忆 6 条
"slang": { "injectMax": 8 }                   // 黑话表 8 条
"gameStudy": { "inject": true }               // 游戏功课：聊到才注入，闲聊 0 字
```

## 5. 频率闸门

```json
"passiveMode": true,                          // 没叫就不说话
"socialV2": {
  "proactive": { "enabled": false },          // 关掉主动冒泡
  "wake": {
    "triggers": { "probability": 0.05 },      // 普通消息 5% 概率
    "probabilityCooldownMs": 1200000,         // 说过话 20 分钟内不再被概率叫醒
    "maxWakePerHour": 8,
    "preSleepWaitMs": 60000                   // 沉睡观察 1 分钟（默认 5 分钟）
  },
  "send": { "maxSendPerMinute": 2, "maxSendPerHour": 20 }
}
```

## 6. 深夜省电

```json
"quietHours": { "enabled": true, "start": 1, "end": 6 }
```

1~6 点只保留「有人明确叫它」的唤醒，关掉概率/主动/到点唤醒。

## 实测数据（2核2G、单群、活跃度中等）

- 优化前：约 220 万 token/天（≈¥3~6）
- 优化后：预计降 30~50%，学习类任务降 90%
- 缓存命中量是输入的 40~60 倍——说明固定注入在反复重放，**这是最该继续削减的地方**
