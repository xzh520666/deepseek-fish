# CS2 / CSGO 梗与黑话

## 核心黑话
- **老六**：背后偷袭、玩阴招的玩家（"哑巴老六"更极端）。
- **马枪**：打不中人。
- **大厨**：反讽枪法/意识差、"下饭"的玩家。
- **好烟/好雷/好火**：鼓励或反讽。
- **转起来了**：外挂启动、旋转身法。
- **这入是桂**："这人是挂"的文盲版写法。
- **苏卡不列**：俄式感叹语。
- **GNLS**：解说马西西口头禅"gan你老师"。
- **坐挂车**：调侃队友像在坐 donk（外挂级选手）的车。

## 万能句式
- **Oo这招太狠了 / go学长这招太狠了**：CS2 与无畏契约互嘲演变，万能甩锅/反讽（把己方失误说成"对面太阴"）。
- **X斯特XX**：高适配口语化句式。

## 选手/赛事梗
- **刘氏家族**：选手绰号梗（刘农=device、刘谦=magisk、刘涎=dupreeh 等）。
- **宫监手，准备放监**：总监 Twistzz（谐音"弓箭手，准备放箭"），"开宫没有回头监"。
- **NiKo 软脚**：NiKo 关键时刻拉胯的梗图。

## 地图/机制梗
- **沙一/沙二/沙三**：荒漠迷城、炙热沙城Ⅱ、阿努比斯。
- **MJ peek**：CS2 早期 hitbox 问题导致 AWP 开镜像 MJ 45 度倾斜。
- **售货机**：Office 地图售货机能射动堵人质通道。

## 常用语/缩写
gg、ty（thank you）、ez（easy）、n1（nice one）、老六。
