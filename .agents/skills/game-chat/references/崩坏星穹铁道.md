# 崩坏：星穹铁道 梗与黑话

## 剧情/角色名台词
- **人有五名，代价有三**：刃的台词，官方反复玩梗。
- **我将点燃大海**：流萤/萨姆 2.0 名场面台词。
- **我为你带来毁灭了**：白厄动画咆哮，因"毁灭"谐音"烩面"，被调侃成"我为你带来烩面了"。
- **帮帮我，史瓦罗先生**：克拉拉大招语音，万能求助句式（联动衍生"帮帮我，肯德基爷爷"）。
- **该喝水了**：饮月君举水瓶 CG，被 P 进各种名场面，形成"龙尊劝饮"表情包。
- **黑塔转圈圈**：追加攻击的洗脑动作+语音，经典表情包。

## 玩法/角色黑话
- **义父 / 赛博义父 / 邮箱出金**：1.6 免费送真理医生，玩家喊"义父"。
- **阮饭**：模拟宇宙吃到阮·梅的强力祝福，"吃到阮饭游戏已经结束了"。
- **红绿灯**：调侃贝洛伯格存护命途敌人（给速度鞋能"单刷星神"）。
- **停云的真实身份**：调侃她名为同谐、实为"存护"，挨打总在第一位。

## 社区黑话
- **欢愉 / 阿哈**：找乐子、看乐子。"娘子~啊哈~"配凤凰传奇歌词出圈。
- **感谢流光忆庭**：感谢有人整理、记录事件全过程（评论常刷）。
- **虚构史学家**：指编造、篡改历史的人，也调侃现实篡改资料。
- **请输入文本**：白厄强度/剧情太逆天，表示"强到说不出话"。
- **尖叫黄金裔**：尖叫饮料瓶身像黄金裔，衍生大量表情包。
- **浓度**：对崩铁梗的熟悉程度；**梗小鬼**：自嘲爱玩梗。

## 版本玩梗（文案爱埋外部梗）
崩铁文案以"高强度冲浪"著称，4.0/4.4 埋了大量外部梗（JOJO"我拒绝"、哆啦A梦、让子弹飞"结巴也算时间"等），聊到版本内容可顺着提。
