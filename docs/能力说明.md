# 能力与调度说明

## 记忆体系（四层）

| 层 | 存储 | 作用 |
|---|---|---|
| 长期记忆 | `state/long-memory.json` | 永久记住人物/偏好/约定/事件；每 40 条消息自动提炼 |
| 跨会话时间线 | 内存（各会话 recentMessages） | 群与私聊混排成一条线，最近 12 小时 / 10 条 |
| 交接备忘 | `state/handoff.json` | 换线前把「现在在聊什么」写下来，新线接着用（48h 有效） |
| 日记 | `state/diary.jsonl` | 每天固定时间写，私聊发给主人 |

## 触发规则（被动模式）

说话：被 @ 且有内容 / 被叫名字 / 被提问 / 被拍 / 私聊 / 明确求助
不打扰：空 @、纯表情、冷场、普通闲聊（只有 5% 概率偶尔插一句，且 20 分钟内说过话就不再触发）

## 学习类后台任务

| 任务 | 频率 | 说明 |
|---|---|---|
| 黑话提取 | 每 10 条群消息 | 提取候选词 → 联网研究 → 出现≥2次且有解释自动确认 |
| 长期记忆提炼 | 每 40 条消息 | 提炼 0~3 条值得长期记的事实 |
| 游戏功课 | 每 8 小时一个游戏 | 联网补术语与梗；聊到某游戏才注入 |
| 交接摘要 | 换线时 | 总结当前上下文 |
| 日记 | 每天 22:30 | 写一条并发给主人 |
| 成本日报 | 每天 09:00 | 统计昨天 token 消耗，不经过模型 |

## 手动触发接口（控制台，端口 3100）

```bash
T=$(cat /opt/qq-bridge/state/console-token)
# 写日记
curl -X POST "http://127.0.0.1:3100/api/diary/run?token=$T" -H 'content-type: application/json' -d '{}'
# 换线（先写交接摘要）
curl -X POST "http://127.0.0.1:3100/api/session/rotate?token=$T" -H 'content-type: application/json' -d '{"reason":"手动"}'
# 补某个游戏的功课
curl -X POST "http://127.0.0.1:3100/api/games/study?token=$T" -H 'content-type: application/json' -d '{"game":"原神"}'
# 预览某个文本会注入哪些游戏功课
curl "http://127.0.0.1:3100/api/games/digest?token=$T&text=原神卡池"
# 查看长期记忆
curl "http://127.0.0.1:3100/api/memory/long?limit=20&token=$T"
# 触发一次唤醒（测试用）
curl -X POST "http://127.0.0.1:3100/api/socialV2/wake?token=$T" -H 'content-type: application/json' -d '{"key":"private:<你的QQ>","reason":"测试"}'
```
