# 小肥鱼 · QQ 群 AI 机器人（DSH 版）

> 本地修改版已加入[记忆 RAG v2](docs/记忆RAG升级.md)：保留原人设规则，
> 新增按会话隔离、相关性过滤、事实纠正与遗忘，以及可选本地向量检索。
> 默认不再跨私聊/群共享模型上下文；真实 QQ/DSH 联调尚未完成。

把一只「像真人群友」的 AI 装进你的 QQ 群：会潜水、会接梗、会记人、会写日记、会发空间，还能在你电脑上的安卓模拟器里看屏幕。

> 这不是一个打包好的 App，而是一套**编排层 + 配置**：需要你准备好服务器、QQ 协议端和 DeepSeek API Key。
> 完整能力依赖 [DeepSeek Harness](https://npmjs.com/package/@deepseek-ai/dsh) 与 SnowLuma。

## 它能做什么

| 能力 | 说明 |
|---|---|
| **真人感群聊** | 二代仿真模式：自己决定何时说话/潜水，短句分条，不客服腔 |
| **被动模式** | 没叫它就不说话；空 @ 不回；只在被 @/提问/私聊时开口 |
| **长期记忆** | 跨会话永久记住「谁喜欢什么、约定了什么、发生过什么」 |
| **跨会话时间线** | 群里说过的话，私聊里接得上；反之亦然 |
| **交接摘要** | 会话满了自动写「备忘」再换新线，换线不失忆 |
| **日记** | 每天固定时间写一条，私聊发给你 |
| **QQ 空间** | 看好友动态、点赞、评论；只在主人要求时才发说说 |
| **黑话学习** | 从群聊里自动提取梗、联网研究含义、确认后注入说话 |
| **游戏功课** | 英雄联盟 / CS / 原神 / 我的世界 / 火影手游 / 崩铁 的术语与梗，聊到才注入 |
| **看手机（可选）** | 通过电脑上的 MuMu 模拟器截图、滑动、发图（低频，不追视频） |
| **成本控制** | 概率唤醒 + 冷却 + 深夜省电 + 上下文压缩 + 便宜模型跑学习任务 |

## 本仓库不包含上游源码

`qq-bridge` 上游未声明 License，因此本仓库**不复制它的代码**，只提供：

- `patches/*.patch`：对本项目所需改动的 unified diff（应用后可复现全部功能）
- `persona/`、`mcp/`、`server/`、`desktop/`：自研配置与脚本

安装脚本会自动拉取上游 v0.1.0 再打补丁。详见 [NOTICE](NOTICE) 与 [patches/README.md](patches/README.md)。

```
   ┌────────────────────┐              ┌──────────────────────────┐

   └────────────────────┘              │ qq-bridge (:3100)         │
                                        │   ↓                       │
                                        │ 你的 QQ 群/私聊            │
                                        └──────────────────────────┘
```

## 快速开始（服务器）

```bash
# 0. 准备：Ubuntu 22.04+，2核2G 起，Node 22，Docker
# 1. 先自己准备 QQ 协议端（SnowLuma），拿到 accessToken
# 2. 再拉本仓库
git clone <本仓库地址> dafeiyu-fish && cd dafeiyu-fish
# 3. 安装（会自动覆盖 overlay、部署 preset/人设卡/日记 MCP/systemd）
sudo bash server/install.sh
# 4. 按脚本最后打印的清单填 config.json、credentials、启动 SnowLuma
bash server/health.sh
```

详细步骤见 [docs/安装.md](docs/安装.md)。

## 成本

- 单账号日消耗约 **¥1~5**（看群活跃度）
- 学习类任务（黑话研究/游戏功课/记忆提炼）已降配为便宜模型 + 低推理
- 深夜 1~6 点自动省电；上下文到 50% 自动压缩
- 详见 [docs/成本控制.md](docs/成本控制.md)

3. **一个 QQ 小号**（不要用主号，风控风险自负）
