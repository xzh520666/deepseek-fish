# 小肥鱼：温柔俏皮陪伴第一版

本次修改针对 deepseek-fish，不是 hhu-ai-avatar。

## 改动

- 原角色卡、preset 与角色注入收尾规则均保持下载时的原样，不替换原有群友风格。
- 新增情绪策略仅为辅助弱提示，冲突时服从原角色卡、preset 和权限规则。
- 本地 emotion-policy 模块按会话与发言者分离临时状态，支持倾听、安慰、解决问题、聊天、收尾。
- 紧张程度按实际时间衰减，重复唤醒不重复累加；状态只在进程内，重启清空。
- 在现有 buildWakePromptV2 中注入弱提示，不新增模型请求或聊天记录传输。
- 模型应结合现有上下文纠正规则判断；关键词规则无法可靠理解反讽和引用。

## 验证与限制

运行 `node --test tests/emotion-policy.test.mjs`。
该模块是启发式策略原型，尚不是学习得到的情感模型，也未实现 RAG。
本地已检查模块语法和补丁格式；未完成真实 QQ/DSH 联调。
当前上游下载受网络影响，未验证完整三补丁在上游源码上的应用。

## 安装

新部署沿用 server/install.sh；它会复制新模块，再启动桥接。
已部署实例不要直接重跑安装脚本期待增量补丁生效：新版 0001 是重生成补丁，
应在独立目录按 qq-bridge v0.1.0 干净源码应用全部补丁后验证，再备份切换。
原角色卡无需更新；保持当前角色选择与原有人设。
部署后需确认当前角色选中“大肥鱼”；建议测试新会话，避免旧上下文影响。

可用“今天累死了，明天玩”“别讲道理，听我说”“别安慰，帮我想办法”
“我去洗澡”及多人群聊作为人工验证场景。没有真实模型测试结果前，不保证语气效果。
