# 安装指南

## 一、准备

| 需要 | 说明 |
|---|---|
| 服务器 | Ubuntu 22.04+，**2核2G 起**（1核1G 会 OOM），建议 4G swap |
| Node.js | 22.x |
| Docker | 用于跑 SnowLuma |
| QQ 小号 | 建议新号，别用主号 |
| DeepSeek API Key | platform.deepseek.com 申请 |

```bash
# Node 22
curl -fsSL https://deb.nodesource.com/setup_22.x | bash - && apt-get install -y nodejs
# Docker
curl -fsSL https://get.docker.com | sh
```

## 二、先起 QQ 协议端（SnowLuma）

本项目**不包含也不转发** SnowLuma 镜像。你需要自行获取镜像，并亲自阅读接受其 EULA：

```bash
docker run -d --name snowluma --restart unless-stopped \
  -p 3000:3000 -p 3001:3001 -p 5099:5099 -p 6081:6081 \
  -e SNOWLUMA_ACCEPT_EULA=1 -e SNOWLUMA_ACCEPT_PRIVACY=1 \
  -e SNOWLUMA_HOOK_AUTOLOAD=1 \
  -v qq-gateway-data:/app/data/config \
  -v qq-client-config:/app/data/QQ \
  <你的 SnowLuma 镜像>
```

- 打开 `http://<服务器IP>:6081`（noVNC）扫码登录 QQ 小号
- 在 `5099` 面板里找到 **accessToken**，后面要用
- 关键：`hookAutoLoad` 必须为 true，否则桥接发消息会失败

## 三、装本项目

```bash
git clone <本仓库> dafeiyu-fish && cd dafeiyu-fish
sudo bash server/install.sh
```

脚本会：覆盖 overlay 三个文件 → 装 DSH → 部署 preset/人设卡/日记 MCP → 写 systemd。

## 四、填配置

```bash
nano /opt/qq-bridge/config.json
```

至少改这四处：

```jsonc
"snowluma": { "accessToken": "<SnowLuma 面板里的 token>" },
"ownerQQ": "<你自己的 QQ 号>",
"allow": {
  "private": ["<你自己的 QQ 号>"],
  "groups": ["<允许说话的群号>"]
}
```

DeepSeek Key：

```bash
mkdir -p /root/.dsh && cat > /root/.dsh/.credentials.yaml <<'YML'
version: 1
refs:
  DEEPSEEK_API_KEY: sk-你的key
YML
```

## 五、启动与体检

```bash
systemctl restart dsh-web qq-bridge
bash server/health.sh
```

看到 QQ 已登录、桥接已连接就成功了。给机器人发条私聊试试。

## 六、可选：电脑侧手机能力

见 `desktop/README.md`。不做也能正常聊天，只是没有「看屏幕/截图」能力。

## 常见问题

**Q: 群里不回复？**
- 检查群号在 `allow.groups` 里
- 看 `journalctl -u qq-bridge -n 50`，常见是 `result=120`（被禁言）或 唤醒限流

**Q: 报 HTTP 400？**
- 上下文撑爆了。确认 `cordis.patch.yml` 里有 `llm-deepseek.config.defaultContextWindow: 128000`，否则 DSH 会以为窗口有 100 万 token，永不压缩

**Q: 内存吃紧？**
- `bash server/harden.sh`（加 swap、给服务和容器设内存上限、每天凌晨自动重启）

**Q: 表情发出去变成图片？**
- 本项目的 overlay 已改用 `send_custom_face`（真表情通道）；若仍异常，检查 SnowLuma 版本是否支持该 action
