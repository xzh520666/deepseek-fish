# 小肥鱼后台管理（前端骨架）

可视化驾驶舱，管理远程服务器上的 qq-bridge。当前是**骨架阶段**：Vue3 单页应用（CDN 引入，无需构建），三个中心的页面结构已就位，记忆中心已能连 3100 API 显示真实记忆。

## 怎么跑

```bash
# 方式一：直接双击 index.html（file:// 协议，需浏览器允许跨域，或改 base 用服务器同源）
# 方式二：起个静态服务
cd web && python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080
```

> 注意：qq-bridge 的 3100 端口默认可能没开 CORS。若浏览器直连报跨域，需要让 qq-bridge 加 CORS 头，或通过同源反代访问。

## 连接参数

- **服务器地址**：qq-bridge 控制台地址，默认 `http://127.0.0.1:3100`
- **console-token**：服务器 `/opt/qq-bridge/state/console-token` 文件里的值
