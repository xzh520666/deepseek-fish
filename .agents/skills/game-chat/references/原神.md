# 原神 梗与黑话

## 出圈梗
- **原神启动**：源自 UP 主门酱（门矢士）玩游戏时高喊"原神，启动！"。模板句式"XXX，启动！"。玩家自嘲"要开始玩原神了"。
- **原神牛逼**：用火影鼬佐助对战剧情的空白对话框填"原神牛逼"，主打"已读乱回"——不管对方说啥发一张就打破尴尬。衍生"天下同牛"系列（鸣潮牛逼/王者荣耀牛逼/绝区零牛逼）。

## 黑话与谐音
- **原**：《原神》简称；**我超，原！** 是玩家看到"原"字的反应梗。
- **原怎你？** = "原神怎么你了？"，玩家面对调侃的常见回应。梗图：士兵喊"我超，原！"，装死的人抬头齐声"原怎你？"。
- **原批**：贬义，指听到批评原神就激烈护主的激进玩家（别主动用，是黑称）。

## 抽卡/玩法梗
- **歪了 / 歪七七**：抽卡歪到常驻角色七七。梗图：23:59 等刷新 → 00:00 开抽 → 00:01 歪七七皱眉，三格火柴人。
- **出金 / 出金了吗**：抽卡抽到五星（金色）。
- **米门永存 / 米姆米哈**：抽卡前"米门永存"，抽卡后变"米姆米哈"（自嘲落差）。
- **非酋**：运气差、抽不到好东西的玩家。

## 常用语
- **启动！**：呼应"原神启动"。
- **不如原神**：万能玩梗句式，别的游戏被拿来和原神比。
- 玩家被调侃时回"原怎你？"。

## 底线
- "原批"是黑称，只用于自嘲或接梗，别主动用来骂人。
