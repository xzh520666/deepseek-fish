# 火影忍者手游 梗与黑话

## 主播带火的梗
- **你已急哭**：嘲讽对手操作变形、心态崩盘的梗（谐音"你已疾苦"）。梗图：CODM 圈 AI 外星人头像 + "你已急哭"文案。用于戏谑对方情绪失控。
- **阿玛忒拉斯**：日语"天照"的空耳，佐助放天照时的台词。梗图/动作：捂脸装痛苦后喊台词，中二式玩法。被主播 coke 夸张模仿后爆火。
- **老弟的压压**：主播鸽子神胡言乱语的"压力"梗（雷压、大压、钢压）。抽象混剪《八连臭火之歌》。

## 角色与强度梗
- **青春哥 / 这就是青春**：忍者"忍战迈特凯"，技能 CD 短、大招伤害高。梗图：王宝强脸 P 到迈特凯身上配"这就是青春"，配 DJ《我的歌声里》。弹幕"曲对人对，超影干碎""一局两大，太青春啦"。
- **普通人直接搂住**：角色长十郎（长得像"普通人"人设的余文乐），无敌帧+抓取极强。梗图：弱势角色逆袭，配"谁敢欺负普通人，我就直接搂住它"。
- **机长/空少/空姐**：调侃超长滞空、无敌帧忍者（桃博、机械鸣人、新春小南），"火影进入大军阀时代"。
- **孩子你无敌了**：吐槽强度失衡的超模忍者（九喇嘛鸣人普攻碾压），反向嘲讽靠版本强势取胜者。有配套表情包。

## 策划/官方梗
- **你喜我做**：战斗策划丁座直播说"只要你们喜欢，我就给你们做忍者"，后被用来嘲讽策划（柱间争议）。
- **谣言不知从何而起**：实习策划乌冬回应争议的发言，玩家用来反驳"放屁言论"。
- **禁术大师**：调侃乱放技能或降智操作（神卡直接开大、霸体顶熊猫）。

## 表情包/常用
- **摸头表情包**：游戏内著名表情，玩家社区代表性梗图。
- **忍者之神**：调侃强度过高的忍者（如刚上线的鹰佐）。

## 烂梗（别用）
- **尿液/尿垢**：新玩家叫"尿液"、老玩家叫"尿垢"，被批评为恶臭烂梗，会伤新玩家。用"木叶的新芽""火之意志的传承者"更友好。
