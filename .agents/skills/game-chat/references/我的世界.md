# 我的世界（Minecraft）梗与黑话

## 生存/萌新黑话
- **火柴盒**：萌新搭的长方体房子；装饰得好叫"高级火柴盒"。
- **要致富，先撸树**：新手先砍树拿木头（衍生"要致富先修路"）。
- **一组 / 64进制**：物品堆叠上限 64，1 组=64 个（梗图"32+32=一组"）。
- **20铁**：萌新炫耀"我有20铁，你怕不怕"。
- **钻石？**：把红石、青金石、发光地衣误认成钻石。
- **香草**：原版（Vanilla 直译）。
- **腐竹**：服主（服务器运营者）谐音。
- **飞翔使**：村民的外号（籽岷小伙伴学村民声音像）。
- **多喝岩浆**：对应"多喝热水"的直男发言（岩浆更烫）。

## 经典梗
- **封印解除 / 半颗心**：Dream 猎人游戏剩半颗心后反杀，弹幕"半颗心——封印解除"。
- **游戏结束**：Dream 开局拿到木头，弹幕调侃"游戏结束"。
- **移除了Herobrine**：更新日志玩笑话，成固定梗。
- **圆**：MC 由方块组成，"MC 里没有圆"，出现圆形就说"世界末日"。
- **2+2=3**：铁砧合并两把时运2镐得时运3，调侃铁砧"加法不对"。
- **一定是OptiFine干的！**：游戏崩溃甩锅给高清修复 Mod。
- **瑞典原神**：MC 的调侃称呼（拿原神开放世界/原石/风之翼类比 MC）。
- **jvav**：小学生把 Java 打成 jvav，成圈内梗（适度玩）。
- **杂兵**：抖音博主"佳一妈妈"称 MC 暴力恐怖，把怪物叫"杂兵"。
- **舰长行为**：虐待村民（UP 主"和谐号舰长"），"不养闲人"。

## 梗图常见题材
苦力怕（两个像素点让人害怕）、村民、钻石、火柴盒、落地水（"降落伞 1783 年才发明，之前的人们："）、挖矿背包满、死亡提示"你现在不能睡觉，附近有怪物在游荡"。
